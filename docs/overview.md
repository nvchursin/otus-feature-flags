# Feature Flags Service

## Description

Сервис для управления фича-флагами. Позволяет настраивать распределение функциональности между пользователями в приложениях.

## Functional Requirements

- Сервис должен предоставлять ui для управления флагами (админка).
- Сервис должен предоставлять api для получения состояния раскатки флагов для конкретного пользователя.
- У приложений должна быть возможность запросить состояние как одного, так и нескольких флагов с батчингом по тегу.
- Один и тот же пользователь в одном и том же окружении гарантированно должен получать одни и те же значения флагов при каждом запросе.
- Сервис должен позволять настроить процент раскатки для каждого флага с точностью до 1%.

## Non-Functional Requirements

- Система делится на четыре основных узла:
  - Админский узел для управления флагами (**ff-crud**).
  - Узел для распространения снапшота актуальной конфигурации флагов (**ff-distributor**).
  - Рантайм-узел, отвечающий за расчёт состояния раскатки флагов на пользователей (**ff-evaluator**).
  - Приложения-потребители, которые используют сервис для получения состояния раскатки флагов (**ff-consumers**).

### ff-crud

- Доступность сервиса должна быть не ниже 80%.
- Время ответа на запросы должно быть не более 1000ms.
- Сервис должен быть закрыт oauth2-авторизацией.
- Сервис должен разворачиваться и функционировать независимо от ff-evaluator.
- Все изменения в системе должны версионироваться и записываться в audit-log.

### ff-distributor

- Любые изменения конфигурации флагов должны распространяться на потребителей в течение 1 минуты.

### ff-evaluator

- Доступность сервиса должна быть не ниже 99.9%.
- Время ответа на запросы: p99 - 100ms.
- Сервис должен выдерживать пиковую нагрузку в 10k rps.
- Допустимое количество ошибок в ответе: 0.1%.

### ff-consumers

- Список актуальных флагов доступен на старте приложения.
- Полученные флаги кешируются в локальном хранилище.
- При отсутствии связи с сервисом приложение продолжает работать, используя кешированные значения флагов или заранее прописанные в коде значения по умолчанию.
