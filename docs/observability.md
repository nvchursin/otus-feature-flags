# Надёжность и наблюдаемость

## Сбои и тактики


| Сбой                         | Тактика первой очереди                      | Драйвер                  |
| ---------------------------- | ------------------------------------------- | ------------------------ |
| `ff-evaluator` недоступен    | Реплики и readiness; кеш/дефолт на клиентах | Доступность 99,9%        |
| Перегрузка                   | Rate limit и таймаут                        | p99 ≤ 100 мс при 10k RPS |
| Снапшот устарел              | Polling 30 с и повтор публикации            | Обновление ≤ 60 с        |
| `ff-crud`/MongoDB недоступны | Изоляция контура вычисления                 | Независимость evaluator  |


## Метрики ключевого сценария `/evaluate`


| RED      | Измеряемое свойство                |
| -------- | ---------------------------------- |
| Rate     | Валидные запросы в секунду         |
| Errors   | Доля `5xx` среди валидных запросов |
| Duration | p99 времени ответа                 |




## Actionable-алерты


| Порог                    | Окно   | Первый шаг                              |
| ------------------------ | ------ | --------------------------------------- |
| `5xx > 1%`               | 5 мин  | Проверить логи/rollout, откатить        |
| `p99 > 100 мс`           | 10 мин | Проверить ресурсы, масштабировать       |
| Снапшот отстаёт `> 60 с` | 5 мин  | Проверить distributor, переопубликовать |




## SLI, SLO и бюджет


| Сценарий     | SLI                     | SLO за 30 дней | Бюджет ошибок           |
| ------------ | ----------------------- | -------------- | ----------------------- |
| Доступность  | Доля запросов без `5xx` | 99,9%          | ≤ 0,1% запросов с `5xx` |
| Скорость     | Доля запросов ≤ 100 мс  | 99%            | ≤ 1% запросов медленнее |
| Актуальность | Доля обновлений ≤ 60 с  | 99%            | ≤ 1% обновлений позже   |




## Grafana


| Панель  | Показатели                      |
| ------- | ------------------------------- |
| RED     | RPS, `5xx`, p99, расход бюджета |
| Ресурсы | CPU, memory, реплики            |
| Снапшот | latest/active version, возраст  |
