# Карта деградации

| Отказ                                   | Что видит пользователь                                        | Что делает приложение                                                                   | Как доставить исправления             |
| --------------------------------------- | ------------------------------------------------------------- | --------------------------------------------------------------------------------------- | ------------------------------------- |
| `ff-evaluator` недоступен / нет сети    | Ничего не замечает                                            | sdk отдаёт кеш последнего снапшота, при пустом кеше — дефолт из кода, ретраит с backoff | Деплой/восстановление сервиса, минуты |
| `ff-crud` недоступен                    | Админ видит ошибку в админке, пользователи не затронуты       | `ff-evaluator` работает на последнем скачанном снапшоте                                 | Деплой/восстановление сервиса, минуты |
| `ff-distributor` не опубликовал снапшот | Изменение флага не применяется дольше минуты, ошибки не видно | `ff-evaluator` работает на предыдущей версии, опрос раз в 30с продолжается              | Деплой/повтор публикации, минуты      |
| `ff-evaluator` перегружен, p99 > 100мс  | Приложение дольше ждёт ответ                                  | sdk по таймауту переключается на кеш/дефолт                                             | Автоскейлинг, минуты                  |
