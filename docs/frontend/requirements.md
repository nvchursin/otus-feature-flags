# Frontend Requirements

## Rendering Model

Client-side rendering, статика загружается с cdn, spa-переходы между страницами.
В нашем случае это приемлемо, так как админка закрыта oauth2 и не требует индексации.

## Driver

Простота разработки и независимый деплой

## Code Splitting

Два чанка:

- Основной: список флагов, редактор флага;
- Дополнительный: аудит-лог изменений с diff-библиотекой: может быть тяжеловесным и используется на порядок реже остальной функциональности.

В перспективе возможно добавление каких-то новых чанков, например для страницы с evaluation simulator — инструмента для статистической проверки раскатки конкретных флагов.

## Metrics

- ttfb низкий благодаря статике с cdn;
- lcp после разделения бандла должен снизиться с базовых 3.5 с до 2.5 с (примерно на 30%).
