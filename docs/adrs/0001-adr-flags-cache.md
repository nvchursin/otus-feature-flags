# ADR: кеширование конфигурации фича-флагов

## Status

Accepted.

## Context

`ff-crud` хранит и изменяет конфигурацию фича-флагов, а `ff-evaluator` использует её при вычислении значений флагов. Эти компоненты должны разворачиваться независимо. При этом изменения конфигурации должны становиться доступными потребителям не позднее чем через одну минуту.

Чтение конфигурации напрямую из бд или через api `ff-crud` каждым экземпляром `ff-evaluator` создаёт связь между контурами управления и вычисления, увеличивает нагрузку на `ff-crud` и делает его отказ частью критического пути.

Для развязывания read/write и evaluate сценариев конфигурация публикуется в формате json в объектное хранилище и раздаётся через cdn.

## Decision

После каждого подтверждённого изменения флагов `ff-crud` формирует полный снапшот конфигурации окружения в json-формате. Снапшот содержит все данные, необходимые `ff-evaluator` для вычисления флагов.

Публикация выполняется с помощью webhook:

- ff-crud делает запрос на lambda-сервис;
- сервис забирает свежий снапшот через специальный endpoint в `ff-crud`, и складывает его в хранилище.

Каждый экземпляр `ff-evaluator` раз в 30 секунд проверяет наличие новой версии конфигурации в хранилище, и если таковая обнаружена, — скачивает её в локальный in-memory cache.

## Consequences

Положительные последствия:

- `ff-evaluator` не зависит от доступности `ff-crud` и его базы данных в момент вычисления флагов;
- cdn принимает на себя запросы на получение конфигурации и позволяет горизонтально масштабировать `ff-evaluator`;
- кеширование снапшотов уменьшает трафик.

Отрицательные последствия и риски:

- конфигурация распространяется не моментально; задержка определяется интервалом опроса и нюансами географии серверов;
- появляются дополнительные компоненты и расходы на эксплуатацию: объектное хранилище, cdn, публикация и мониторинг снапшотов.

Альтернативные решения, которые не были выбраны:

- прямое чтение данных в `ff-evaluator` через бд/api `ff-crud` — снижает общую пропускную способность системы, и делает отказ `ff-crud` частью критического пути.
